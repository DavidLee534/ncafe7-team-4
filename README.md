# 고양이 연금술 카페

고양이 사장이 운영하는 연금술 공방 겸 카페 웹사이트입니다. 손님은 정해진 메뉴를 고르는 대신 재료를 연금솥에 넣어 자신만의 포션(음료)을 조합합니다.

> 냥냥 사장님의 비밀 레시피, 오늘은 어떤 포션을 빚어볼까?

## 기획 개요

- **핵심 경험:** 재료 선반에서 고른 재료를 연금솥에 넣고 포션을 완성하는 온라인 조합 경험
- **차별점:** 일반 메뉴판 대신 재료 선반과 연금솥을 사용하며, 조합 결과에 따라 포션 이름·효과·등급이 달라집니다.
- **대상:** 테마 카페와 인증샷을 즐기거나 커스텀 음료를 선호하는 20~30대
- **톤앤매너:** 살짝 엉뚱하고 귀여운 판타지. 고양이 사장의 안내 문구는 `~냥` 말투를 쓰되, 가격과 재료 정보는 정확하고 명확하게 표시합니다.

## 세계관과 캐릭터

카페는 숲속 오래된 탑 1층에 있는 공방입니다. 은퇴한 대연금술사인 고양이 사장이 인간에게 커피 연금술을 전수하기 위해 가게를 열었습니다.

| 캐릭터                 | 역할                  | 사이트 활용                    |
| ---------------------- | --------------------- | ------------------------------ |
| 사장 고양이 (예: 모카) | 대연금술사, 가게 주인 | 메인 인사, 조합 결과 평가 멘트 |
| 견습생 고양이          | 재료 담당             | 재료 선반 설명 툴팁            |
| 부엉이 점원 (선택)     | 주문·계산 담당        | 장바구니, 결제 안내            |

카페 이름은 **nyan cafe**입니다. 사이트 안에서는 고양이 점장 모카가 운영하는 `냥금술 공방`을 대표 세계관 명칭으로 함께 사용합니다.

## 포션 조합 시스템

계열마다 **기반 재료를 반드시 하나** 선택하고, 해당 계열에 맞는 추가 재료 선반을 열어 포션을 완성합니다. 디저트와 푸드는 같은 방식으로 연성합니다.

| 구분   | 계열     | 연금술 이름      | 기반 재료 (필수 1개)                    | 추가 재료                          | 완성 예시                                             |
| ------ | -------- | ---------------- | --------------------------------------- | ---------------------------------- | ----------------------------------------------------- |
| 음료   | 커피     | 어둠의 물약      | 원두: 다크, 라이트, 디카페인            | 시럽, 우유, 토핑                   | 바닐라 + 다크 + 우유 → 빛과 어둠의 균형 포션          |
| 음료   | 논커피   | 대지의 물약      | 초코, 말차, 고구마, 곡물                | 우유, 시럽, 토핑                   | 말차 + 오트 + 꿀 → 숲의 숨결 포션                     |
| 음료   | 과일라떼 | 열매의 물약      | 과일청: 딸기, 블루베리, 망고            | 우유, 과육, 크림                   | 딸기청 + 우유 + 휘핑 → 분홍 고양이 포션               |
| 음료   | 티       | 약초 달임        | 얼그레이, 캐모마일, 히비스커스, 녹차    | 과일청, 꿀, 허브                   | 캐모마일 + 꿀 → 잠드는 꼬리 포션                      |
| 음료   | 스무디   | 정령의 진액      | 냉동 과일: 딸기, 망고, 바나나, 블루베리 | 요거트, 우유, 꿀                   | 망고 + 요거트 → 태양 정령의 진액                      |
| 음료   | 프라페   | 얼음 결정 엘릭서 | 모카, 쿠키앤크림, 녹차, 카라멜 + 얼음   | 시럽, 휘핑, 토핑                   | 쿠키 + 휘핑 + 초코칩 → 눈보라 엘릭서                  |
| 디저트 | 디저트   | 연성 과자        | 케이크 시트, 와플, 크로플, 마카롱 쉘    | 크림, 과일, 소스, 장식             | 크로플 + 바닐라 아이스 + 캐러멜 소스 → 황금 비늘 과자 |
| 푸드   | 푸드     | 모험가의 식량    | 크루아상, 치아바타, 베이글, 토스트      | 속재료(햄, 치즈, 에그, 채소), 소스 | 베이글 + 크림치즈 + 연어 → 바다 사냥꾼 식량           |

### 감정 연금술

재료 연금술과 분리된 빠른 메뉴 추천 기능입니다. 손님은 **오늘의 기분 1개**와 **끌리는 맛 0~2개**를 고르고, 시스템은 기본 메뉴 30종에 사전 정의된 태그를 비교해 가장 어울리는 메뉴를 처방합니다.

| 구분 | 선택 규칙 | 항목 |
| --- | --- | --- |
| 오늘의 기분 | 필수 1개 | 피곤함, 열정, 그리움, 울적함, 설렘, 긴장됨 |
| 끌리는 맛 | 선택 0~2개 | 달콤한, 쌉싸름한, 상큼한, 고소한, 시원한, 따뜻한 |

- 메뉴의 기분 태그가 일치하면 **+3점**, 맛 태그가 일치할 때마다 **+2점**을 부여합니다.
- 가장 높은 점수의 기본 메뉴를 추천하며, 동점일 때는 사전에 정한 메뉴 순서를 따릅니다.
- 추천 결과는 새 메뉴가 아니라 기존 기본 메뉴이므로 가격·재고·주문 정책을 그대로 사용합니다.

| 음료 토핑 | 0~3개 | 휘핑, 초코칩, 시나몬 파우더, 마시멜로, 과육, 타피오카 펄 |
| 디저트 장식 | 0~3개 | 생크림, 아이스크림, 제철 과일, 초코 소스, 캐러멜 소스, 베리 소스, 견과류 |
| 푸드 속재료 | 1~4개 | 햄, 치즈, 에그, 아보카도, 연어, 채소, 크림치즈 |
| 티 블렌딩 | 과일청 0~1개 + 허브 0~1개 | 과일청: 레몬청, 자몽청, 유자청, 청귤청 / 허브: 민트, 레몬그라스, 로즈마리, 라벤더 |
| 푸드 소스 | 0~2개 | 바질 페스토, 허니머스터드, 홀그레인 머스터드, 스리라차 마요, 발사믹 글레이즈 |
티 블렌딩은 과일청과 허브 묶음에서 각각 하나씩, 전체 최대 두 개를 고릅니다. 과일라떼 기반 재료와 구분하기 위해 티에는 시트러스 과일청만 둡니다. 푸드 소스는 최대 두 개까지 선택하며, 치아바타 샌드위치의 기본 바질 페스토는 0원입니다.

| 가격 단계 | 단가 | 대상 |
| --- | ---: | --- |
| 기본 포함 | 0원 | 라떼 계열의 일반 우유, 메뉴 기본 구성 재료 |
| 기본 | +500원 | 시럽, 대체우유, 일반 토핑, 과일청, 허브, 푸드 소스 |
| 특별 | +800원 | 요거트, 마시멜로, 과육, 타피오카 펄, 생크림, 견과류, 햄, 치즈, 에그, 채소 |
| 고급 | +1,500원 | 아이스크림, 제철 과일, 아보카도, 연어, 크림치즈 |

가격 예시: 다크 로스트 + 바닐라 + 오트는 **5,000원**, 캐모마일 + 꿀 + 레몬청은 **5,500원**, 치아바타 샌드위치 + 아보카도 + 허니머스터드는 **9,000원**입니다.

### 조합 결과 규칙

기본 메뉴는 **연금술 이름을 크게**, **기본 이름을 작게** 표시합니다. 추가 재료를 넣은 메뉴도 같은 형식을 따르며, 기본 연금술 이름은 유지한 채 재료 수식어를 앞에 붙입니다.

```text
[추가 재료 수식어] + [기본 연금술 이름]
```

| 조합 | 연금술 이름(크게) | 기본 이름(작게) |
| --- | --- | --- |
| 다크 로스트 | 칠흑 고양이의 물약 | 다크 로스트 커피 |
| 다크 로스트 + 헤이즐넛 | 숲향 품은 칠흑 고양이의 물약 | 다크 로스트 커피 · 헤이즐넛 |
| 말차 + 꿀 | 꿀빛 숲의 숨결 | 말차 라떼 · 꿀 |
| 와플 + 아이스크림 | 눈꽃 얹은 격자 결계 와플 | 와플 · 아이스크림 |
| 캐모마일 + 꿀 + 레몬청 | 꿀빛 · 햇살 스민 잠드는 꼬리 | 캐모마일 티 · 꿀 · 레몬청 |

| 추가 재료 수 | 이름 생성 방법 |
| --- | --- |
| 0개 | 기본 연금술 이름을 그대로 사용 |
| 1~2개 | 수식어 1~2개 + 기본 연금술 이름 |
| 3개 이상 | 우선순위가 가장 높은 수식어 1개 + 효과 칭호 + 기본 연금술 이름 |

효과 칭호는 재료 효과 태그의 합이 가장 높은 태그로 정합니다.

| 효과 태그 | 칭호 |
| --- | --- |
| 달콤함 | 달콤한 축복의 |
| 활력 | 깨어나는 |
| 진정 | 고요한 |
| 상큼함 | 산뜻한 바람의 |
| 고소함 | 고소한 들녘의 |
| 든든함 | 든든한 모험의 |
| 시원함 | 서늘한 겨울의 |

효과 태그는 기반 재료와 추가 재료를 모두 합산하며, 동점이면 `활력 → 진정 → 달콤함 → 상큼함 → 고소함 → 든든함 → 시원함` 순서로 결정합니다.

예: 다크 로스트 + 캐러멜 + 오트 + 휘핑 → **달콤한 축복의 · 황금빛 칠흑 고양이의 물약**

#### 예외와 계산 원칙

1. **비밀 레시피는 고정 이름을 사용합니다.** 정해 둔 재료 조합과 정확히 일치하면 일반 규칙 대신 비밀 레시피 이름으로 덮어씁니다.
2. **등급은 이름 바깥에 배지로 표시합니다.** 이름에 희귀·전설을 넣지 않고 `✦ 희귀`, `✦✦ 전설`처럼 표현합니다.
3. **같은 조합은 항상 같은 이름을 가집니다.** 재료 선택 순서와 무관하게 수식어를 우선순위 순으로 정렬합니다.
4. **효과 문구와 등급은 서버에서 계산합니다.** 재료 효과 태그를 합산해 문구를 만들고, 궁합 점수로 일반·희귀·전설을 결정합니다.
5. **가격은 실시간 합산합니다.** 기본 메뉴 가격에 선택한 추가 재료 가격을 더해 표시합니다.

#### 이름 생성에 필요한 데이터

`ingredient`에는 다음 이름 생성용 속성이 필요합니다.

| 컬럼 | 예시(바닐라) | 용도 |
| --- | --- | --- |
| `modifier` | 빛을 머금은 | 이름 앞에 붙는 수식어 |
| `modifier_priority` | 30 | 수식어 정렬 및 3개 이상일 때 대표 수식어 선택 |

- 기반 재료는 기본 메뉴의 연금술 이름과 기본 이름을 갖습니다.
- 추가 재료는 수식어와 우선순위를 갖습니다.
- 감정 연금술은 재료 데이터와 분리한 메뉴 매칭 데이터로 관리합니다. 각 기본 메뉴에는 `emotion_tags`, `taste_tags`를 두고, 선택값과의 점수로 기존 메뉴 하나를 추천합니다.
- 기존 화면의 초안 이름은 기본 메뉴와 겹치지 않는 `빛과 어둠의 균형 포션`, `바다 사냥꾼 식량`만 비밀 레시피로 유지합니다. 나머지는 위 수식어 규칙으로 생성합니다.

## 부가 기능

- **레시피 도감:** 발견한 포션과 비밀 레시피를 모읍니다. 미발견 항목은 실루엣으로 표시합니다.
- **오늘의 추천 포션:** 사장 추천 조합을 한 번에 담습니다.
- **포션 공유:** 조합 결과를 링크로 공유하고, 다른 손님도 그대로 주문할 수 있습니다.
- **주문:** 완성 포션을 장바구니에 담아 매장 픽업 주문을 진행합니다.
- **재료 선택 안내 말풍선** 엘릭서 선택 시 기반재료와 부가재료를 안내한다. 기반재료는 필수이며, 부가재료는 선택 사항이다.

## 디자인과 인터랙션

- **색상:** 딥 네이비·다크 브라운 배경에 앰버 골드(촛불)와 재료별 포션 색을 포인트로 사용합니다.
- **글꼴:** 제목은 손글씨·고서풍 세리프, 본문과 가격은 Pretendard 같은 가독성 좋은 산세리프를 사용합니다.
- **일러스트:** 고양이 사장, 재료 병, 연금솥, 플라스크를 플랫한 2D 스타일로 통일합니다.
- **조합 인터랙션:** 재료 클릭 또는 드래그 시 솥 안으로 떨어지고, 재료가 추가될수록 액체 색이 섞여 변합니다.
- **완성 연출:** 연기·반짝임 효과 뒤 포션 병을 표시합니다.
- **캐릭터 모션:** 고양이 사장은 꼬리 흔들기와 눈 깜빡임 대기 모션을 가집니다.
- **반응형:** 모바일에서는 재료 선반을 하단 탭으로 배치하고 연금솥을 중앙에 둡니다.

상단 내비게이션에서는 **연금 공방**을 가장 눈에 띄게 배치합니다. 메인에서 연금 공방, 도감, 장바구니, 마이페이지 등 6개 페이지로 이어지며, 공방에서 만든 포션이 이후 기능으로 흐릅니다.

### 바뀐 규칙 (연금 공방)

- 재료 이름 · 가격 · 색 · 효과 태그 · 수식어는 `ingredients` 테이블에서 읽는다. 테이블에 없는 규칙만 `service/AlchemyRules.java` 에 둔다
- 계열에 연결된 선반만 열고 제외 재료는 뺀다. 선반별 개수: 시럽 0~2, 우유 0~1, 음료 토핑 0~3, 디저트 장식 0~3, 푸드 속재료 1~4, 티 블렌딩(과일청 1 + 허브 1), 푸드 소스 0~2. 어기면 400
